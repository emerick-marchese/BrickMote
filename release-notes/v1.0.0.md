Première version de **BrickMote**, un logiciel de bureau à distance **chiffré de bout en bout**, sans compte, sans licence et sans limite de durée ou de nombre de sessions. Il utilise les mêmes ports qu'AnyDesk : TCP 6568 (puis 443 et 80) pour le relais, TCP 7070 en direct, UDP 50001 pour la découverte.

### Windows

1. Lancez `BrickMote-Setup-1.0.0-Windows-x64.exe`. Les fichiers ne sont pas encore signés : si SmartScreen affiche « Windows a protégé votre ordinateur », cliquez sur *Informations complémentaires* puis *Exécuter quand même*.
2. Choisissez les options proposées :
   - raccourci sur le bureau ;
   - **lancement au démarrage de Windows**, dans la zone de notification, pour que le PC reste joignable ;
   - **règles de pare-feu** pour les connexions directes (TCP 7070) et la découverte (UDP 50001), limitées aux réseaux privés.
3. BrickMote apparaît dans le menu Démarrer. Pour le désinstaller : *Paramètres > Applications*. Vos réglages et votre ID sont conservés lors d'une mise à jour.

### macOS

Ouvrez le `.dmg` et glissez BrickMote dans **Applications**. L'application n'est pas encore signée par Apple. Au premier lancement :
- macOS 15 ou plus récent : *Réglages Système > Confidentialité et sécurité > Ouvrir quand même* ;
- versions précédentes : *clic droit > Ouvrir*.

Pour pouvoir être contrôlé, autorisez BrickMote dans *Confidentialité et sécurité*, rubriques **Enregistrement de l'écran** et **Accessibilité**.

### Linux

```
sudo apt install ./BrickMote-1.0.0-Linux-x64.deb
```

BrickMote apparaît ensuite dans le menu des applications (commande `brickmote`). Pour être contrôlé, une session **X11** est nécessaire (Wayland n'est pas pris en charge).

### Vérifier un téléchargement

Comparez son empreinte avec la liste en bas de cette page :
- Windows : `certutil -hashfile <fichier> SHA256` ;
- macOS et Linux : `shasum -a 256 <fichier>`.

## Fonctionnalités

- **Connexion** par ID à 9 chiffres (via votre serveur relais), par adresse IP, ou par ID sur le réseau local (découverte automatique)
- **Contrôle** de la souris et du clavier (raccourcis, Ctrl+Alt+Suppr), multi-écrans, trois niveaux de qualité, lecture seule
- **Presse-papiers**, **transfert de fichiers** dans les deux sens (vérifié par SHA-256) et **chat**
- **Accès interactif** (la personne accepte, avec un code de sécurité) ou **sans surveillance** (mot de passe + double authentification TOTP)
- **Postes** en grandes vignettes avec aperçu, petites vignettes ou liste ; onglets Récents, Favoris et Réseau local
- **Wake-on-LAN** : réveil d'un PC via votre box (IP publique ou DynDNS) sur le port UDP de votre choix, et sur le réseau local
- **Thème sombre** (thème clair au choix), interface en français

## Sécurité

- Chiffrement de bout en bout X25519 + Ed25519 + AES-256-GCM : le serveur relais ne voit jamais le contenu des sessions
- Mot de passe jamais transmis (SPAKE2), verrouillage après 5 échecs, double authentification TOTP
- ID auto-certifiant et clés épinglées : un poste ne peut pas être usurpé
- Liste blanche, postes bloqués, droits modifiables pendant la session, journal de sécurité
- Pas de mode caché : un panneau reste affiché sur le PC contrôlé tant qu'une session est ouverte

Détails : `SECURITY.md`. Le code n'a pas encore fait l'objet d'un audit de sécurité externe.

## Serveur relais (pour se connecter par ID depuis Internet)

```
docker compose -f deploy/docker-compose.yml up -d
```

Copiez ensuite l'empreinte du certificat affichée par le serveur dans *Paramètres > Réseau* de chaque poste. Voir le `README.md`.

## Limites connues

- Pas de son, ni d'impression à distance
- Windows : l'écran de connexion et les fenêtres UAC ne sont pas contrôlables (il faudrait un service système)
- Linux : X11 obligatoire côté PC contrôlé
