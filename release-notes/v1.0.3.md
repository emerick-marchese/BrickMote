**BrickMote 1.0.3** : mot de passe demandé automatiquement, et mémorisable.

- **Le mot de passe est demandé automatiquement** quand le poste distant accepte l'accès sans surveillance. Plus besoin de cocher une case avant de se connecter. Un bouton « Demander l'autorisation » reste disponible pour passer par la personne devant l'écran. Pendant la saisie, le poste distant n'affiche aucune demande.
- **« Mémoriser le mot de passe sur ce PC »** : les connexions suivantes à ce poste se font directement. Seule une clé dérivée, valable uniquement pour ce poste, est conservée (chiffrée par Windows). Elle est oubliée automatiquement si le mot de passe du poste change, et peut être effacée depuis le menu ⋮ du poste (« Oublier le mot de passe enregistré »).

- **Une fenêtre annonce les mises à jour au lancement de BrickMote.** Quand une nouvelle version existe, elle s'affiche dès l'ouverture, avec la liste des nouveautés, « Installer maintenant » ou « Au prochain démarrage », et une case « Ne plus afficher pour cette version ». Au démarrage automatique de Windows, c'est une simple notification.

Les PC Windows installés se mettent à jour automatiquement au prochain démarrage.
