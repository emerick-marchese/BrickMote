**BrickMote 1.0.1** : serveur relais intégré, rien à configurer.

## Nouveautés

- **Serveur relais par défaut** : BrickMote se connecte tout seul au serveur relais officiel. La connexion par ID fonctionne directement via Internet, sans réglage.
- **Adresse du serveur masquée** : elle n'apparaît ni dans l'application (état, paramètres, messages d'erreur), ni dans le code source public. Elle est intégrée à la compilation depuis un secret GitHub et brouillée dans l'exécutable.
- **Paramètres > Réseau** : choix entre le *serveur BrickMote (par défaut)*, *mon propre serveur relais* ou *aucun* (réseau local et adresse IP directe uniquement). Si vous aviez déjà configuré votre propre relais, ce réglage est conservé.
- **Relais plus discret** : un nouveau certificat ne contient plus le nom « BrickMote », que les moteurs de recherche de serveurs (Shodan…) indexent.
- **Mises à jour automatiques signées** : sous Windows (version installée), les nouvelles versions s'installent seules au démarrage du PC, sans fenêtre ni clic. Sur les autres systèmes, un bandeau propose le téléchargement. Toute mise à jour dont la signature Ed25519 ou l'empreinte SHA-256 est incorrecte est refusée.
- Option `--version` : affiche la version et indique si un serveur par défaut est intégré.

> **Depuis la 1.0.0** : cette version n'a pas encore de système de mise à jour. Installez la 1.0.1 une fois à la main, avec l'installateur ci-dessous (vos réglages et votre ID sont conservés). Les versions suivantes s'installeront ensuite toutes seules.
